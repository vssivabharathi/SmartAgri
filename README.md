# Conditions for this repo
```
[] Checkout the branch 
[] Don't push to the main branch 
[] Do a meaningful commit message

```
use this conventional method for git commits

| Type       | Use for                |
| ---------- | ---------------------- |
| `feat`     | New functionality/work |
| `fix`      | Bug/error correction   |
| `docs`     | Documentation          |
| `refactor` | Code restructuring     |
| `data`     | Dataset changes        |
| `model`    | ML/model changes       |
| `config`   | Configuration changes  |
| `chore`    | General maintenance    |
